AppCrashlyticsServiceImpl class

An implementation of AppCrashlyticsService that integrates with Firebase Crashlytics.

This service is responsible for initializing global error handlers across the Flutter framework, platform dispatcher, and current isolate to automatically catch and report unhandled exceptions. It also provides methods to manually log errors and identify users for crash tracking context.
