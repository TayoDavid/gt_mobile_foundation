AppFirebaseConfigImpl class

A configuration service that handles the initialization of Firebase services.

This class encapsulates the setup process for Firebase, including configuring the core app options and activating FirebaseAppCheck for security verification using platform-specific providers (Play Integrity for Android, App Attest for Apple).
