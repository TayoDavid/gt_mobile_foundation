AudioPlayerService

AudioPlayerService class

An implementation of AppMediaPlayer that handles audio playback.

This service encapsulates a just_audio AudioPlayer instance. It listens to the player's internal streams and broadcasts state changes via stateStream, allowing the rest of the application to react to audio events uniformly.
