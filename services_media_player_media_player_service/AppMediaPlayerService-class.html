AppMediaPlayerService

AppMediaPlayerService class abstract

Defines the unified strategy interface for all media players.

This interface abstracts the underlying player implementations (like video, audio, and youtube) so that the MediaPlayerService can interact with them polymorphically without needing to know the specific controller types.
