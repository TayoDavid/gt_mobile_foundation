MediaPlayerService

MediaPlayerService class

A facade service that orchestrates various media players using the Strategy Pattern.

This service acts as the central point for loading and controlling media. It dynamically assigns the appropriate AppMediaPlayer implementation based on the MediaSource type (audio, video, or youtube) and delegates playback commands to it.
