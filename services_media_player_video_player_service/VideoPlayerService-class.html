VideoPlayerService

VideoPlayerService class

An implementation of AppMediaPlayer and CaptionablePlayer that handles video playback.

This service encapsulates a VideoPlayerController. It internally converts the controller's ValueNotifier updates into a reactive stateStream so that the UI can bind to video playback state seamlessly using the unified pattern.
