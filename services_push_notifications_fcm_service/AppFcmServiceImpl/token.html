token property

  1. @override
Future<String?> get token
override

Retrieves the unique Firebase Cloud Messaging token for this device.

This token is used by the backend to target push notifications specifically to this installation of the app. Returns null if the token cannot be fetched.

Implementation

@override
Future<String?> get token async {
  try {
    return await _fcm.getToken();
  } catch (e, t) {
    _reportError(e, t);
    return null;
  }
}
