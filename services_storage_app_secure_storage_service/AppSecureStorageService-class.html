AppSecureStorageService

AppSecureStorageService class

A secure implementation of AppStorageService utilizing flutter_secure_storage.

This service encrypts all stored data, making it suitable for sensitive information such as authentication tokens and user credentials. On iOS, it uses the Keychain. On Android, it uses EncryptedSharedPreferences.
